# Carousel Playbook

How to make a carousel in your brand. Process: skill `carousel-create`. Your design tokens replace any reference palette.
Proposals only: nothing here changes your channel rules.

## Format
- **1080×1350 px (4:5)**, 7–10 slides, one idea per slide, ≤ 40 words per slide.
- Safe margins: 90 px sides, **130 px top and bottom**; the renderer draws each slide inside an **84 % frame** so Instagram and Buffer
  never crop it. Instagram allows **5 hashtags** at most.
- Animated version (optional): everything visible from frame 0 (faded), entering in < 1 s, silent, 5 s, 30 fps.

## Slide roles
| # | Role | What goes there |
|---|---|---|
| 1 | **Hook** | one big line that threatens or promises; one accent word; series tag |
| 2 | Context / stakes | why it matters now, one sentence, a number (marked "example data" if illustrative) |
| 3…n-2 | **Items** | one per slide: title + one-line benefit + proof (a number, a mini chart, a screenshot in a card) |
| n-1 | Twist / summary | the one thing to remember, or before → after (use the `compare` slide) |
| n | **Keyword CTA** | "Comment WORD and I'll send…" + "Save this" |
Fixed on every slide: counter "02 / 07", handle chip, swipe hint (not on the last).

## Copy rules
- The first slide **threatens or promises**, never explains.
- Answer objections in pairs of slides (objection → answer).
- One verdict per slide in one sentence.
- The caption repeats the keyword and sets the tone; only promise what exists.

## Four skeletons
1. **Countdown / Top N** — hook → item N…1 → summary → CTA.
2. **Myth or objection ladder** — identity-threat title → myth + verdict × 5 → what works → CTA.
3. **Hook / template list** — hook (2–4 slides) → lists of fill-in lines → CTA.
4. **Concept explainer** — one concept per slide with a definition, an example and a mistake to avoid.

## Publishing
Skill `buffer-publishing-setup`: carousel = **Post**, files one by one in order 01…N, verify the order afterwards.

## Key Takeaways
- 7–10 slides, 4:5, one idea each, hook first, keyword CTA last.
- Same template across a series: counter, handle, swipe hint.
- Render from data so every carousel is exact and repeatable.
