# rawcc — content-creation inbox

Everything new about **making videos** arrives here: references whose editing, script or sound you want
to copy or study. The AI reads this folder and never edits your files. The folder around it, `Content/`,
is the database where processed items are filed by category.

> **Optional.** Sending reference videos is *Route A*. If you have none, *Route B* builds your style from your design system alone;
> you can add references at any time (see `docs/VIDEOS-CON-O-SIN-REFERENCIAS.md` in the project).

## What goes here
- **Web Clipper notes.** Import `_web-clipper-template.json` once (Obsidian Web Clipper → Settings →
  Templates → Import). Clip a reel, video or post: it lands here as a note with `status: pending`.
  Web Clipper's plain default template works too.
- **One folder per reference** with videos, a `links.txt` (one address per line), a `notes.txt` saying what
  you liked and whether editing, script or both matter, screenshots or written scripts.
- Loose video or audio files.

Things to *learn* (not to copy) go to `Knowledge-Sources/rawc/`.

## What happens when you say "process rawcc" (or "process rawc and rawcc")
Only when you ask. Skill `luisart-procesar-referencias`.
1. Download the links (public pages only).
2. **Video and audio always go through Whisper**; the transcript is the source, never the title.
3. Analyse the **editing** in depth: framing, captions, text, animations, images, pacing, hook, CTA, music,
   SFX timing.
4. Analyse the **script and diction**: hook type, beats, words per minute, pauses, tone, devices, CTA, and a
   reusable script template.
5. Make sample renders of the copyable elements (in the project's `out/`, never in the vault).
6. Write the notes into `wiki/Content Creation/References/`, update `Creators/` and feed `Scripts/`.
7. **File the source by category** under `Content/`: `Creators/<creator>`, `Editing Styles`,
   `Scripts and Diction`, `Sound and Music`, `Animation and Motion`, `Other`. Nothing is deleted.

Analyses only propose: your styles and rules change only when you decide.
